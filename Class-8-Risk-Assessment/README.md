# Class 8 Lab: Quantitative Risk Assessment & Data Classification

## Overview
This lab evaluates cybersecurity risk using quantitative risk assessment and applies data classification and privacy frameworks to business scenarios.

## Objectives
- Calculate Single Loss Expectancy (SLE).
- Calculate Annualized Loss Expectancy (ALE).
- Evaluate the financial value of a proposed security control.
- Apply HIPAA, GDPR and PCI-DSS considerations.
- Assign internal data classification levels.

## Scenarios
1. Global Logistics Corp. — Intrusion Prevention System (IPS) risk assessment.
2. MediCare Plus — Data classification and privacy frameworks.

## Deliverables
- Completed lab assignment
- Risk calculations and cost-benefit analysis
- Data classification decisions
- Scenario application responses

## Tools & Concepts
- Quantitative risk assessment
- SLE, ALE, AV, EF and ARO
- Risk mitigation
- Data classification
- HIPAA, GDPR and PCI-DSS
